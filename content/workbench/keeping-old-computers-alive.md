An older computer isn’t always finished just because it feels slow. In many cases, the problem isn’t the hardware itself. It might just need a clean operating system installation, a solid-state drive, more RAM, or a lighter operating system.

## Topics in this note

- Wiping and reinstalling the operating system
- Replacing a mechanical hard drive with an SSD
- Adding RAM when it helps
- Cleaning out unnecessary software
- Trying a lighter operating system like Linux
- Checking whether the hardware itself is actually bad

This is based on real experiences working on older machines over the years. Not every computer can or should be saved, but many of them still have useful life left.

## What I learned

Most older computers can still do useful work if you match the right operating system to the hardware and keep the system clean.

## What I’d do differently

I would check storage health earlier before spending time on software troubleshooting.

## Tools & Parts (examples)

- SSD (2.5″ or M.2, depending on model)
- RAM (compatible with machine)
- USB installer (Windows / macOS / Linux)
- Basic screwdriver set
- Backup drive for data transfer
